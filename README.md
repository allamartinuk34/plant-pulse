# Plant Pulse

Native Android app (Kotlin + Jetpack Compose), generated by Android App Factory.

- Gradle 9.6.0 wrapper, AGP 9.4.1 (built-in Kotlin 2.2.10), Compose Compiler plugin 2.2.10,
  versions in `android/gradle/libs.versions.toml`
- Gradle root: `android/` — `cd android && ./gradlew assembleRelease bundleRelease`
- Sources: `android/app/src/main/java/<package>/`
- UI: Jetpack Compose + Material 3, Single Activity (ComponentActivity + setContent),
  ViewModels with StateFlow, navigation as a state machine in a ViewModel
- Images: `android/app/src/main/res/drawable/` (painterResource)
- Keep rules: `android/app/src/main/keepRules/rules.keep`

## How this overlay works

`template-kotlin-compose/` is NOT a complete template. `generate-kotlin.sh --ui compose`
copies `template-kotlin/` first (wrapper, manifest, launcher icons, backup rules, strings),
then copies every file of this directory on top of it, then deletes the paths listed in
`DELETE.list` (the XML layout and colors.xml). Keep the two Version Catalogs in sync when
bumping AGP / SDK: `template-kotlin/android/gradle/libs.versions.toml` and
`template-kotlin-compose/android/gradle/libs.versions.toml`.
